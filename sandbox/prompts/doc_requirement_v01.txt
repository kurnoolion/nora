STEP 1 — Identify the subdomain. US MNO device specs cover many distinct technical areas. Before generating any phrase, decide which of the following families this requirement belongs to (a requirement may belong to more than one):

- LTE EMM/NAS — attach, detach, TAU, EMM timers (T3402/T3346/etc.), EMM cause codes, EPS bearer, PDN connectivity. Refs: 3GPP TS 24.301, TS 23.401, TS 36.331.
- LTE RRC/Access — RRC connection, RACH, PRACH, idle/connected mode, PLMN selection, cell selection. Refs: TS 36.331, TS 36.304.
- 5G NR/NAS — 5G registration, NR bands (n1-n79, n257-n261), beam management, 5G NAS, 5G PDU sessions. Refs: TS 38.300, TS 38.331, TS 24.501.
- 5G Core — AMF, SMF, UPF, PCF, NRF, NSSF, network slicing, service-based interfaces. Refs: TS 23.501, TS 23.502.
- VoLTE/IMS — IMS registration, SIP signaling, RTP/RTCP, P-CSCF discovery, voice call setup, supplementary services. Refs: TS 24.229, TS 23.228, TS 24.628, GSMA IR.92/IR.94.
- VoWiFi/Untrusted-WLAN access — ePDG selection, SWu interface, IKEv2/IPSec tunnel, EAP-AKA authentication, IMS-over-WLAN registration, voice call continuity. Refs: TS 23.402, TS 33.402, TS 24.302, RFC 7296, GSMA IR.51/IR.61.
- WLAN/WiFi — 802.11 association, ANQP/Hotspot 2.0, WPA2/WPA3, EAP methods, BSSID/SSID selection. Refs: IEEE 802.11, Hotspot 2.0 Release 3.
- eSIM/RSP — Profile download, EID/ICCID, SM-DP+/SM-DS, profile installation, LPA. Refs: GSMA SGP.21, SGP.22, TS.34.
- SMS — SMS over GERAN/LTE, SMS-CB (Cell Broadcast), CMAS/WEA alerts, SMSC routing. Refs: TS 23.040, TS 23.041.
- Device Management — OMA-DM, OMA LwM2M, firmware update (FOTA), bootstrap, configuration. Refs: OMA-DM 2.0, TS.42.
- Voice continuity / SRVCC / handover — VoLTE→VoWiFi handover, SRVCC, ePDG↔PGW path switch, idle-mode mobility between 3GPP/non-3GPP. Refs: TS 23.216, TS 23.402.
- Device capabilities / form factor — applicability rules, supported bands, supported features, power class, antenna config.

If the requirement spans multiple subdomains, treat all of them as in-scope for phrase generation.
