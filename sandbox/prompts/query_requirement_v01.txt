STEP 1 — Identify the subdomain the query is asking about. US MNO device specs span TWO broad families: standards-body protocol layers (3GPP / GSMA / IETF / IEEE / OMA / SGP), AND the device's software stack and user-facing surfaces (Android platform / apps / UI / hardware). A query may target either family or both.

STANDARDS-BODY subdomains:
- LTE EMM/NAS, LTE RRC/Access — attach, detach, EMM timers (T3402/etc.), TAU, RRC connection, PRACH. Refs: TS 24.301, TS 36.331.
- 5G NR/NAS, 5G Core — 5G registration, NR bands, 5G NAS, network slicing, AMF/SMF. Refs: TS 24.501, TS 23.501, TS 38.331.
- VoLTE/IMS — IMS registration, SIP signaling, P-CSCF, voice call setup, supplementary services. Refs: TS 24.229, GSMA IR.92.
- VoWiFi/Untrusted-WLAN — Wi-Fi Calling, ePDG, SWu, IKEv2/IPSec, EAP-AKA, IMS-over-WLAN. Refs: TS 23.402, TS 33.402, GSMA IR.51.
- WLAN/WiFi — 802.11, ANQP, Hotspot 2.0, WPA2/WPA3.
- eSIM/RSP — Profile download, EID/ICCID, SM-DP+, LPA. Refs: SGP.21, SGP.22.
- SMS — SMS over LTE, Cell Broadcast, CMAS/WEA. Refs: TS 23.040, TS 23.041.
- Device Management — OMA-DM, OMA LwM2M, FOTA. Refs: OMA-DM 2.0.
- Voice continuity / SRVCC — VoLTE↔VoWiFi handover, SRVCC, ePDG↔PGW path switch. Refs: TS 23.216, TS 23.402.
- Device capabilities (RF) — supported bands, form factor, power class, antenna config, SAR.

PLATFORM / APP / UX subdomains:
- Android Platform / Telephony API — TelephonyManager, SubscriptionManager, ImsManager, CarrierConfigManager; CarrierConfig keys; system properties; HAL/AIDL; AOSP CDD/CTS; Android version + API level.
- Android Applications — Dialer / Settings / Messaging / LPA apps; package names; Activity/Service classes; manifest permissions; intent actions.
- UI / UX / strings — settings menu paths, notification channels, dialog wording, screen flows, accessibility, RTL.
- Device hardware / modem / RF — chipset (Qualcomm/MediaTek/Samsung), baseband firmware, AT commands, antenna tuning, GNSS, Bluetooth, FCC ID.
- Privacy / security / regulatory — KeyStore, BiometricPrompt, FCC/FDA/ADA compliance, location-privacy strings.
- Carrier services / VAS — RCS Universal Profile, MaaP, RBM, carrier-bundled apps.
